# 本地固定说明图

默认 `#原神帮助` 已打包为本地图片。`#原神登录说明`、`#原神功能` 也直接读取 `resources/help/` 中预生成的 JPEG，发送时不启动浏览器、不调用 AI。命令末尾加 `文字` 保留文字说明。

公开内容由 `lib/help-content.mjs` 定义，使用 AI-Plugin 的纯固定帮助模块离线生成。manifest 对公开源和图片分别做 SHA-256 校验，内容变化后需重新生成；插件自带相同纯 reader，未安装同级 AI-Plugin 仍可发送固定说明图，缺图或校验失败才回退原文字。自定义前缀不复用默认前缀说明。

动态二维码、安全验证链接、账号和查询结果不存入这些公开图片。授权、AES 加密账户存储和原有权限保持原逻辑。
