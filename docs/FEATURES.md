# 当前功能、依赖与缺口

0.1.0，国服原神优先。独立核心加选择性原插件组合，不等于重写或完成五个仓库全部功能。“独立实现”表示代码已写入本项目；“组合”表示依赖外部源码、宿主、授权/缓存和数据源。两者都不代表本人账户、真实 QQ 图片与发送已经验收。

## 独立核心

默认命令前缀为 `#原神`，同时提供 `api.mjs` 和 CLI。

个人记录文字受 `maxReplyChars` 限制，默认 3500；超过上限的本人私聊记录可导出完整 JSON，群内仍按上限截断。不能把 JSON 请求实现说成全部字段已有图形展示。API 层另有 characterDetail、avatarSkill、activities、gcg/matchList、char_master、hard_challenge/popularity 等分支，部分没有聊天菜单，也需实际授权验收。QQ、绑定 UID、账户备注、Cookie 与账户备份统一加密；整份独立祈愿、订阅路由与去重状态也采用 AES-256-GCM，原生明文账户管理入口停用。祈愿文件名由密钥和对应 AAD 计算 HMAC-SHA256，路径不含 QQ/UID；主动导出的 UIGF 是明文交换文件。旧祈愿在启动和读取时加密迁移，回验后清理未变更的旧文件；错误密钥验证失败，拒绝创建另一套空记录；旧实例其他明文数据与外部面板/群榜缓存须另行审计、迁移，不能推断全部外部缓存已加密。实例数据不提交 GitHub。

## 可选组合模块

`providers.miao/genshin/xhh/fanSky` 默认 false。原目录、固定 commit、许可与加载配置见 [组合说明](NATIVE-PROVIDERS.md)。不加载上游顶层入口；当前源码选择 miao 9 + genshin 13 + xhh 9 + FanSky 1，共 32 类，本轮完整部署仍待验收，实际以 `loaded/partial/error/missing/disabled` 为准。此前宿主的 40 类装载、Runtime.MysInfo/NoteUser/e.user 与 FanSky 资源证据来自加密约束收紧前，不能证明当前全部个人命令或真实 QQ 发送成功。

| 来源 | 选择范围 | 主要功能与前提 |
| --- | --- | --- |
| miao-plugin | character/poke/profile/stat/wiki/gacha/admin/help/alias 的原神规则，禁 miaoApiInfo | 图片面板、伤害/换装、圣遗物评分、练度/天赋/群排名、剧诗/危战、图鉴/素材/日历、角色与关系卡、戳一戳；使用公开面板或加密核心的本次会话授权；未接入的旧接口安全拒绝 |
| Yunzai-genshin | 排除 noteZzz/user/userAdmin/setPubCk/payLog/gcLog，逐处理函数加原神守卫 | 公开攻略/模拟抽卡/公告与探索等只读模块；不启用原生 Cookie/UID 写库、公共池、充值 authkey 和旧祈愿链接缓存。札记/家具/七圣协议已加入加密会话，原图片调用参数和真实响应仍须验收，不能仅因类已加载声称可用 |
| xhh-TL | TL、teamDamage、role_combat、miniRoleCombat、gsAllAbyss、abyssTeam、hardTeam、holdRate、nanokaAbyss；不导入 resinPush/autoSign/autoBbsCoin | 体力卡、全部深渊、小剧诗、幻想角色、配队/持有率、队伍伤害、公开挑战配置；无 stoken 保存/兑换，米游币社区功能待后续加密支持；签到与提醒用独立 AES 核心订阅 |
| FanSky_Qs | 仅 Teyvat BotEntry | `#小助手队伍伤害`、`#单人评级`、成就/宝箱统计与群榜；专属单人算法与完整第三方响应未实测，规则更新额外限主人 |

喵喵帮助只保留 `#喵喵帮助`；小火花使用 `#队伍伤害`，FanSky 对照命令独立命名。裸 `#体力` 转为只查原神；选择器检查其他游戏前缀与游戏状态。源码注册与守卫测试不能替代所有特殊 URL/输入格式的实测。原入口全局 CK 刷新、删除 CK hook、验证码服务部署、定时清理、AI/群管/娱乐与启动下载均不引入。

原 genshin 活动到期推送会无条件访问星铁源，本组合移除其自动/手动任务，普通原神公告查询保留；ledgerTask 规则与后台 task 也移除。原聊天内源码/图库更新规则移除，升级要重新审计并配置。原生账户库不会接收 Cookie/UID 同步；`native-accounts.mjs` 通过 AsyncLocalStorage 从当前 QQ 的 AES 账户创建临时读对象，本次处理结束后失效，save/initCache/addQueryUid 不落盘、不写 Redis CK 池。默认群内只提供 UID，个人授权查询限私聊；明确启用群查询时仍只用请求者本人授权，不借用被 @ 的账户。

扫码由本项目原创 `#原神扫码登录` 提供，国服优先。所选 Yunzai-genshin 的 `apps/user.js` 本身没有扫码获取/轮询实现；原 `#绑定Cookie`/私聊 Cookie 自动检测会写明文原生库，已停用，统一使用加密核心绑定。小火花的裸 `#扫码登录` 提示来自其他生态登录插件，不是本组合新命令；短信登录未实现。

## 验收

已有离线账户隔离/加密、祈愿、请求协议、订阅去重和选择器测试；无账号凭据的真实官方扫码端点已验证 create/pending，研究另有公开源当次探测。它们不证明本人扫码确认、角色归属及凭据保存完整链路、个人记录、完整伤害图、真实群榜或真实自动签到成功。当前最终部署仍在进行，须核对逐模块状态、宿主 runtime 的 NoteUser/MysInfo、在线协议端发送、Cookie/stoken 归属与第三方完整响应。

包体协议已用无凭据国服公开端点核对：2026-10-07 分支/Sophon 返回 `7.1.0`，传统 ZIP 返回 `5.5.0`，预下载为空。该当次观察证明需要显示过期链接标签，不能用旧 ZIP 冒充当前安装包。`resourceBytes` 为接口给出的去重资源大小，不保证最终磁盘占用、更新临时空间或实际网络耗用。
