# 当前功能、依赖与缺口

0.1.0，国服原神优先。独立核心加选择性原插件组合，不等于重写或完成五个仓库全部功能。“独立实现”表示代码已写入本项目；“组合”表示依赖外部源码、宿主、授权/缓存和数据源。已有一个本人国服账户扫码/AES 保存与四项个人 API 的真实验证；缓存新版已部署，真实 Redis 合成迁移验收通过，未通过个人接口与 QQ 图片/发送仍另列。

个人记录文字受 `maxReplyChars` 限制，默认 3500；超过上限的本人私聊记录用内存 Buffer 发送完整 JSON，群内仍按上限截断。CLI command 输出 JSON 到 stdout，CLI login 显示终端二维码，不产生持久明文导出；显式 CLI export 是用户主动的明文交换例外。不能把 JSON 请求实现说成全部字段已有图形展示。API 层另有 characterDetail、avatarSkill、activities、gcg/matchList、char_master、hard_challenge/popularity 等分支，部分没有聊天菜单，也需实际授权验收。

QQ、绑定 UID、账户备注、Cookie 与账户备份统一加密；整份独立祈愿、订阅路由与去重状态也采用 AES-256-GCM，原生明文账户管理入口停用。祈愿文件名由密钥和对应 AAD 计算 HMAC-SHA256，路径不含 QQ/UID；旧祈愿/订阅在启动或读取时加密迁移，密文回验后才清理确认未变的旧源；错误密钥拒绝另建空库。新增原生面板、账本、FanSky/xhh 文件与受控 Redis 缓存加密已部署，32 个原生类和核心均加载；真实 Redis Lua 合成旧数据迁移、凭据剥离、排名顺序、原始键删除已通过，测试键已清理。精确范围见组合说明，不能把列明路径适配扩展成对任意第三方文件的保证。实例数据不提交 GitHub。

扫码由本项目原创 `#原神扫码登录` 提供，国服优先。所选 Yunzai-genshin 的 `apps/user.js` 本身没有扫码获取/轮询实现；原 `#绑定Cookie`/私聊 Cookie 自动检测会写明文原生库，已停用，统一使用加密核心绑定。小火花的裸 `#扫码登录` 提示来自其他生态登录插件，不是本组合新命令；短信登录未实现。
