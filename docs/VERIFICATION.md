## 持久化与隔离

账户库及其滚动备份、祈愿记录、订阅、个人墨安 Key 均加密。原生 miao Data 缓存、指定直接文件缓存和指定 Redis 命名空间经过加密适配；旧明文迁移必须先核对密文，原始数据变化、密钥不匹配或校验失败时停止迁移。受保护路径、Redis 命名空间及限制详见 [组合说明](NATIVE-PROVIDERS.md)。不能据此宣称整个 bot 的所有第三方插件数据都已加密。

本人授权按 QQ 与原神 UID 隔离，原生明文 Cookie 绑定入口停用，账号数据和本地私密配置不进入 Git。Bot 的个人文件通过内存 Buffer 上传，超过 8 MiB 时先在内存中 gzip；压缩后仍超限时拒绝发送，防止宿主自动落明文临时文件。CLI 不自动保存扫码图或命令 JSON。本人明确执行 CLI `export` 指定输出文件时会导出可移植的明文 UIGF，这是主动导出行为。

人工验证 HTML 也由内存生成并上传，显式加载的外部脚本仅为极验官方 `https://static.geetest.com/static/tools/gt.js`，页面不含 Cookie、UID 或设备标识，不自动提交回执。QQ 浏览器不支持时，可下载该 HTML 用系统浏览器打开并亲自操作；成功后复制页面生成的完整 `#原神提交验证 nonce 回执` 命令回同一 QQ 私聊。会话最多 256、创建冷却十五秒、五分钟 TTL；QQ/UID/Cookie 哈希和挑战绑定，回执一次性提交。`#原神取消验证`、切换或解绑清理会话，设备与短期放行信息只在内存，不使用 solver 或自动解题。

实例密钥位于仅本地保存的私密配置中，需与密文一同保管。换错密钥会停止解密，不会自动重置账户库。用户离开或解绑后，不会让其他 QQ 继承其授权。
